# Тренировки 2.0

Локальное PWA-приложение для планирования и учёта тренировок на iPhone.

Основная версия размещена на GitHub Pages: https://skrippy549.github.io/my-training/

## Возможности
- Сегодня, календарь, программы, банк упражнений, прогресс и профиль.
- Несколько активных программ, разовые тренировки и журнал фактических подходов.
- Записи веса и замеров, цели, графики и отчёты.
- Оценки самочувствия до и после тренировок.
- Локальное зашифрованное хранилище AES-GCM, пароль, экспорт и импорт резервных копий.
- Офлайн-режим после первой успешной загрузки.

Личные записи не отправляются в GitHub — они остаются в хранилище браузера устройства.

При первом запуске можно создать новую базу 2.0. Если обнаружится хранилище 1.0, можно также выбрать перенос или **«Начать с чистой базы 2.0»**.

**Важно:** функциональные тесты пройдены в среде разработки. Полный набор проверок на реальном iPhone ещё не завершён. Рекомендуется проверять сохранение и резервное копирование перед внесением ценной истории.

## Ветки
- `main` — приложение 2.0 (GitHub Pages).
- `develop/v2` — исходная разработка и автоматические тесты в каталоге `v2/`.
- `backup/v1-before-v2` — точка отката к предыдущей версии 1.0.

Запуск для локальной проверки: `python -m http.server 8000`. Открыть http://localhost:8000.
