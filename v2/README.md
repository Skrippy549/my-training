# Тренировки 2.0.1

Локальное веб-приложение для планирования тренировок и ведения зашифрованного дневника на iPhone.

**Приложение:** https://skrippy549.github.io/my-training/

## Возможности

- Пять вкладок: «Сегодня», «Календарь», «Программы», «Прогресс», «Профиль».
- Несколько активных программ и разовые тренировки; журнал фактически выполненных подходов, весов и повторений.
- Оценки самочувствия до и после, измерения тела, цели, графики и отчёты.
- Зашифрованное локальное хранение (AES-GCM / PBKDF2), экспорт и восстановление резервных копий.
- PWA: установка на домашний экран и использование без интернета после успешной первой загрузки.

## Изменения 2.0.1

- Исправлено выравнивание кнопок на странице «Сегодня» и вертикальные отступы в разделе «Прогресс».
- Исправлены горизонтальные переполнения в полях выбора даты и времени на узких экранах.
- В форме разовой тренировки можно сразу добавить несколько упражнений из банка, а после сохранения открыть журнал выполнения.
- Завершённые тренировки можно исправлять прямо из карточки, без перевода статуса в «В процессе». Допускается корректировка подходов, весов, повторений и заметок, а также добавление или удаление упражнения из результатов с подтверждением.
- Добавлено 35 редактируемых стартовых упражнений для семи категорий. В уже созданную базу они добавляются один раз, без уничтожения пользовательских записей.

## Данные и безопасность

Личные данные хранятся только в зашифрованном хранилище браузера устройства и не загружаются в GitHub. При обновлении кода база сохраняется; приложение не требует повторного ввода старых результатов. На случай очистки локального хранилища рекомендуется регулярно сохранять зашифрованные резервные копии в «Файлы».

## Разработка и тестирование

- Ветка `main` — опубликованная версия.
- `develop/v2` — исходники, тесты и предыдущие итерации в каталоге `v2/`.
- `backup/v1-before-v2` — резервный снимок версии 1.0.

После обновления 2.0.1 пройдены модульные тесты, браузерные smoke-тесты и регрессия на экранных ширинах 320/375/393/430 CSS px. Полная проверка с настоящим Safari на реальном iPhone по-прежнему требуется.
