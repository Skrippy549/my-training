# Тренировки 2.0 — рабочая сборка (не релиз)

**Статус:** разработка, первая функциональная сборка. Текущую опубликованную версию 1.0 не заменяет.

## Уже реализовано

- Mobile-first тёмный интерфейс с красными акцентами и 5 основными вкладками.
- Создание локального зашифрованного хранилища (PBKDF2/SHA-256, AES-GCM), пароль при полном перезапуске, ручная блокировка.
- Выделенная новая база, сохранение старого хранилища 1.0 без удаления. Миграция 1.0 с сохранением исходных отметок, заметок, веса и отдельного исторического самочувствия. Программа 1.0 восстанавливается как редактируемый прогрессивный план с ближайшего следующего понедельника.
- Создание повторяющихся и конечных программ, добавление занятий и упражнений, простые операции редактирования, архивирование и восстановление.
- Календарь месяц/неделя, разовые тренировки и внесение результатов задним числом.
- Начало и завершение тренировок, обязательные явные оценки до/после в обычном режиме, отсутствие обязательных оценок задним числом, учёт отдельных подходов и статусов.
- Замеры тела, несколько записей веса в день, цели, настройка болевых зон, базовые сводки и отчёты.
- Шифрованный экспорт/импорт с проверкой пароля и защитным шагом экспорта текущей базы перед заменой.
- PWA manifest и кэш приложения (без сетевых обращений с личными данными).

## Что ещё НЕ завершено

- Полная синхронизация правок шаблонов по выбранным/будущим неделям без изменения истории; дополнительные фильтры и справочники банка упражнений.
- Полноценные графики всех силовых показателей, боли до/после, расширенное сравнение замеров, подробные недельные/месячные отчёты и корректные сравнения незавершённых периодов.
- Полный редактор целей и история смены целевых значений.
- Дополнительные проверки совместимости PWA/Safari/iPhone и разных контейнеров хранения, тесты переустановки, аварийных восстановлений и обновлений service worker.
- Углублённое тестирование интерфейса, форм, локализации, дат и защиты данных. В текущей версии ряд форм и экранов упрощён.

## Запуск и проверки

Статический веб-проект. Для теста разместить **всю папку `v2`** под HTTPS либо локально на `localhost` (не открывать `index.html` напрямую как `file://`, т.к. ES-модули и service worker требуют соответствующего происхождения).

```bash
node ./tests/core.test.mjs
python ./tests/browser_smoke.py
```

Модульные тесты используют реальный WebCrypto Node.js. Smoke UI тест использует `about:blank` и **только в тестовой среде** подменяет WebCrypto и localStorage, потому что браузер в изолированной среде блокирует переход на локальный HTTP; такой тест не доказывает корректную работу криптографии в браузере iPhone.

**Безопасность:** до завершения тестирования на iPhone не вводить единственные экземпляры важных данных, не публиковать эту сборку вместо версии 1.0. Разработка ведётся только в ветке `develop/v2`.
