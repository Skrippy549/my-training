# Тренировки 2.0 — рабочая сборка (итерация 2, не релиз)

**Статус:** разработка на `develop/v2`. Не подменять опубликованную версию 1.0.

## Готово и доступно в тестовой сборке

- Пять основных вкладок в темно-графитовом дизайне с красными акцентами.
- Зашифрованное локальное хранилище с AES-GCM и PBKDF2, ручная блокировка, пароль после перезапуска.
- Миграция записей из 1.0 в отдельное хранилище, без удаления исходных данных 1.0 и без выдуманных фактических повторений или самочувствия «до/после».
- Программы, разовые тренировки, календарь, выполнение подходов с раздельными плановыми и фактическими значениями, оценки самочувствия до и после; необязательные оценки при внесении задним числом.
- Банк упражнений: категории, поиск и фильтры по мышечным группам/оборудованию/месту, избранное, скрытие; собственные значения справочников можно вводить в редакторе. Изменение характеристик не изменяет плановые веса/повторы и сохранённые результаты.
- Прогресс: несколько взвешиваний в день, замеры тела, просмотр истории, сравнение двух дат в таблице с обозначением пропусков «Нет данных».
- История упражнений: переключение графиков максимального выполненного веса, объёма нагрузки (вес × повторы) и максимальных повторений в одном подходе. Отсутствующие числовые значения не превращаются в нули.
- Самочувствие: график боли по выбранной зоне с двумя линиями «До/После», архивные значения сохраняются; хронологические раскрывающиеся карточки тренировок.
- Отчёты: неделя/месяц, фильтры по программе и активности, сравнение равных по длительности фрагментов незавершённых периодов; базовые значения веса, энергии и статусов.
- Цели: создание, редактирование целевого значения с историей изменений, архивирование, восстановление и удаление архивной цели. Зоны боли: добавление, редактирование, скрытие и восстановление.
- Зашифрованный экспорт/импорт с необходимым подтверждением сохранения страховочного файла перед заменой базы.
- PWA manifest и service worker для кэширования оболочки приложения; переход на новую версию кода не должен прерывать открытую тренировку.

## Осталось перед выпуском

1. **Критично:** версии шаблонов тренировок и действие «Сохранить» с выбором области применения (текущая неделя, выбранные недели, все будущие) без изменения уже прошедшего расписания и истории. Сейчас изменение базового шаблона может затронуть отображение прежних незавершённых дат. До исправления не применять редактор к ценной истории.
2. Полный конструктор с удобным управлением подходами и параметрами каждого упражнения; полное поведение пользовательских метрик тела, расширение справочников, календарные предупреждения о пересечениях программ.
3. Уточнение крайних случаев отчётов и статусов, проверка исторических записей, сценарии отмены/сбоя сохранения и восстановления.
4. **Критично:** реальные проверки PWA, настоящего браузерного WebCrypto, миграции и обновлений на iPhone Safari/«На экран Домой». В этом окружении локальная HTTP-навигация Chromium блокируется администратором.
5. UI/UX-полировка на узких экранах, клавиатуре iOS и доступности, регрессионное тестирование до публикации.

## Тесты

В каталоге `v2`:

```bash
node tests/core.test.mjs
node tests/analytics.test.mjs
python tests/browser_smoke.py
```

`core.test.mjs` и `analytics.test.mjs` запускаются с реальным WebCrypto Node.js. `browser_smoke.py` проверяет интерфейс через Chromium в `about:blank`, **подменяет шифрование и localStorage только в тестовой среде**. Это не проверка защиты данных на iPhone.

Для ручной проверки разместить каталог `v2` под HTTPS / localhost. Не открывать `index.html` как `file://`: ES-модули и PWA требуют допустимый origin.

**Безопасность:** не вводить единственный экземпляр важных данных в тестовую сборку. Действующую 1.0 и её данные не изменять до подтверждения надёжности миграции.
